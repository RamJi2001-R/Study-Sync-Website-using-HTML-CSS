# StudySync – Responsive Landing Page 🌐

StudySync is a modern and fully responsive landing page built using **HTML5** and **CSS3**.  
This project represents an educational platform UI with a clean design, smooth animations, and well-structured layout.

## 📌 Project Overview
The landing page includes multiple sections such as:
- Navigation bar
- Hero section with call-to-action
- Company trust section
- Features grid
- Testimonials
- Newsletter subscription
- Footer with links and social icons

This project is ideal for practicing **frontend fundamentals** and showcasing UI skills.

## 🚀 Features
- Fully responsive design (mobile, tablet, desktop)
- Modern UI/UX layout
- CSS animations and hover effects
- Clean and readable code structure
- Reusable components
- Newsletter and testimonial sections

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- Google Fonts (Inter)
